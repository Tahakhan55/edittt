## ✨ What is edittt?

edittt is a **free, open platform** built to provide one powerful universal AI and professional file-editing tools for the community. Every tool runs in your browser — your files never leave your device.

## 🚀 Features

### 🤖 Universal AI Assistant
- Chat with Claude Opus — ask anything, upload any file
- Solution-oriented responses — solves your problem, not just answers
- No sign-up required, completely free

### 🖼️ Professional Image Editor
- Fabric.js canvas with full editing tools
- Text, shapes, brush, eraser, crop, layers
- Undo/redo, zoom, export PNG/JPG/WebP
- AI-powered tools: remove background, enhance, magic edit

### 🎨 edittt 4.9 Premium Editor
- Reve-like professional image editing
- Clean dark modern interface
- Precision tools for professional results

### 📄 PDF Editor
- View, edit, annotate PDFs
- Merge, split, compress, rotate pages
- Add signatures and annotations

### 🔍 OCR Scanner
- Tesseract.js text recognition
- Extract text from images and scanned documents
- Multiple language support

### 🔄 Universal Format Converter
- **114+ formats** across 13 categories
- Image, Document, Spreadsheet, Presentation, Audio, Video, Data, Code, Subtitle, Archive, Ebook, CAD, Adobe
- Dynamic conversion options (quality, compression, resolution)

### 🏗️ AutoCAD & Adobe Support
- DWG, DXF, DWT, IFC, STEP, STL, OBJ, FBX
- PSD, AI, INDD, XD, AEP, PRPROJ, FIG, Sketch

### 📝 Document & File Editors
- Edit any text, code, or document format
- Auto-detect file type and provide appropriate tools

## 🚀 Quick Start

### Local Development
```bash
# Clone the repository
git clone https://github.com/tahakhan/edittt.git
cd edittt

# Open in browser
start index.html
```

### Deploy to Vercel
```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```
