## 4️⃣ Dev.to Blog Post

**Title:** I Built a Free AI Image Editor That Rivals Paid Tools — Here's How

**Body:**
# I Built a Free AI Image Editor That Rivals Paid Tools — Here's How

Every image editor I found online was either paid, had watermarks, or required sign-up. So I built **edittt** — a completely free, browser-based platform that combines AI assistance with professional editing tools.

## What It Does

### 🤖 AI Assistant
Chat with Claude Opus directly in the browser. Upload files, ask questions, get instant analysis.

### 🖼️ Professional Image Editor
Full Fabric.js canvas with:
- Text editing (fonts, colors, alignment)
- Shapes (rectangles, circles, triangles, arrows)
- Freehand brush & eraser
- Crop tool
- Layers panel with reordering
- Undo/redo (30 steps)
- Export to PNG/JPG/WebP

### 🔄 Universal Converter
114+ formats across 13 categories:
- Images, documents, spreadsheets
- Audio, video, data formats
- Code, subtitles, archives
- AutoCAD, Adobe files

### 📄 PDF Editor
View, edit, annotate, merge, split, compress — all in the browser.

### 🔍 OCR Scanner
Extract text from images using Tesseract.js.

## Tech Stack

```javascript
// Frontend - pure vanilla JS
const stack = {
  editing: 'Fabric.js',
  pdf: 'PDF.js',
  ocr: 'Tesseract.js',
  ai: 'Claude API',
  hosting: 'Vercel'
};
```

## Privacy First

The biggest design decision: **all processing happens client-side**. Your files never leave your browser. The only server call is for the AI chat (via Vercel serverless functions).
