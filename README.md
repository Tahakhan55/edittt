**edittt** is a free, open-source platform that puts the power of AI and professional file editing right in your browser. Edit images like Reve, convert 114+ file formats, chat with Claude AI, scan documents with OCR, edit PDFs — all without leaving your browser. Your files never leave your device.

## 🛠️ Tech Stack

```
Frontend:    HTML5 / CSS3 / JavaScript (ES6+)
AI Chat:     Claude Opus API
Image:       Fabric.js, Canvas API
PDF:         PDF.js
OCR:         Tesseract.js
Hosting:     Vercel (Serverless)
Backend:     Vercel Serverless Functions
```
